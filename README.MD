
# AI Support Portal

An IT support portal built with Python, Flask and SQLite.

## About the Project

This project is part of my IT portfolio.

The goal is to demonstrate practical skills in IT support, web development, databases and troubleshooting.

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- Git and GitHub

## Current Features

- Create IT support tickets
- Categorize tickets
- Assign ticket priorities
- Store tickets in SQLite
- View registered tickets
- Update ticket status
- Color-coded priorities and statuses

## Planned Features

- AI-assisted troubleshooting
- IT knowledge base
- Search and filtering
- Improved user interface
