Problemer med Wi-Fi

Hvis du ikke får koblet til Wi-Fi, prøv følgende:

  1. Kontroller at Wi-Fi er aktivert.
  2. Start PC-en på nytt.
  3. Sjekk om andre enheter kan koble til nettverket.
  4. Glem nettverket og koble til på nytt.

Outlook starter ikke

Hvis Outlook ikke åpner seg, prøv følgende:

  1. Kontroller at Outlook ikke allerede kjører.
  2. Start PC-en på nytt.
  3. Prøv å starte Outlook i sikker modus.
  4. Kontakt IT-support hvis problemet fortsetter.
